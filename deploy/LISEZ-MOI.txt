========================================================
   GARAGE — Installation sur votre Mac
========================================================

L'application s'installe en une fois. Ensuite elle démarre
toute seule à chaque fois que vous allumez votre Mac.


ÉTAPE 1 — Lancer l'installeur
------------------------------------------------------

Dans ce dossier, repérez le fichier :

      install.command

Faites un double-clic dessus.

Une fenêtre noire s'ouvre, l'installation démarre, elle
prend moins d'une minute. Aucun mot de passe ne vous sera
demandé.

Si macOS vous demande l'autorisation d'accéder au dossier
Téléchargements, acceptez.


SI MACOS REFUSE DE L'OUVRIR
------------------------------------------------------

macOS bloque par défaut les programmes téléchargés sur
Internet. Un message du type « impossible d'ouvrir car
le développeur ne peut pas être vérifié » apparaît.

C'est normal, et voici comment passer outre. La méthode
ci-dessous fonctionne sur toutes les versions de macOS :

   1. Ouvrez le Terminal :
      appuyez sur Cmd + Espace, tapez « Terminal »,
      puis Entrée.

   2. Dans la fenêtre du Terminal, tapez exactement
      ces cinq caractères, le dernier étant une espace :

            bash

   3. Sans rien taper d'autre, faites glisser le fichier
      « install.command » depuis le Finder et lâchez-le
      dans la fenêtre du Terminal.
      Son emplacement s'écrit tout seul.

   4. Appuyez sur Entrée.

L'installation démarre.


ÉTAPE 2 — C'est tout
------------------------------------------------------

À la fin, votre navigateur s'ouvre sur l'application.

Vous trouverez aussi une application « Garage » dans
votre dossier Applications personnel. Glissez-la dans
le Dock, en bas de l'écran : ce sera votre raccourci
de tous les jours.

La première fois, l'application vous demandera votre
nom, votre société et vos coordonnées. C'est à remplir
une seule fois.


UNE NOTIFICATION APRÈS L'INSTALLATION
------------------------------------------------------

macOS affichera sans doute un message du type
« Élément en arrière-plan ajouté ». C'est normal : c'est
ce qui permet à l'application de démarrer toute seule.

Vous la retrouverez dans :

      Réglages Système > Général > Ouverture

Laissez l'interrupteur activé. Si vous le désactivez,
l'application ne se lancera plus au démarrage.


AU QUOTIDIEN
------------------------------------------------------

  - Vous allumez votre Mac : l'application démarre seule.
  - Vous cliquez sur l'icône « Garage » dans le Dock.
  - Vous travaillez.
  - Vous éteignez : tout est conservé.

Vos données ne quittent jamais votre Mac. Elles ne sont
envoyées sur aucun serveur, et l'application n'est
accessible que depuis cet ordinateur.


VOS SAUVEGARDES
------------------------------------------------------

Chaque jour à 12h30, une copie complète de vos clients,
véhicules, interventions et PDF est enregistrée dans :

      iCloud Drive / Garage-Sauvegardes / (date du jour)

Les 30 derniers jours sont conservés.

Si un jour votre Mac tombe en panne, ces dossiers
contiennent tout ce qu'il faut pour repartir.


SI QUELQUE CHOSE NE VA PAS
------------------------------------------------------

L'application ne s'ouvre pas ? Cliquez l'icône « Garage » :
elle relance le service toute seule s'il s'est arrêté.

Si cela ne suffit pas, redémarrez le Mac.

Si le problème persiste, les journaux techniques sont
dans votre dossier personnel, sous :

      Bibliothèque / Logs / Garage /

Envoyez le fichier « erreurs.log » à Noah.


METTRE À JOUR
------------------------------------------------------

Pour installer une nouvelle version : téléchargez le
nouveau dossier et relancez « install.command ».

Vos données sont conservées — l'installeur ne touche
jamais à votre base de clients.
